# Nexo Legal Estudio

Sitio institucional jurídico preparado como demostración profesional de portfolio.

## Funciones

- Diseño responsive
- Presentación de áreas legales
- Formularios demostrativos
- Panel administrativo local en `/admin`
- Botones de contacto y WhatsApp
- Protección contra indexación mediante `noindex` y `robots.txt`

## Tecnologías

- Next.js
- React
- TypeScript
- CSS responsive
- Persistencia local con `localStorage`

## Estado

Proyecto conceptual. Los formularios no envían información a un estudio real y los datos se guardan únicamente en el navegador actual.

## Ejecución local

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run start
```
